# Course track A roadmap

Checkpoint one implements the imported template's Python harness, Docker-only tools, service boot, desktop/CLI connection, v0 contracts, ADRs and fifteen B1–B5 tasks. The selected development inference route is gpt-6-luna through the optional authenticated local Codex bridge; default Compose is offline mock. Docker Desktop Linux Engine is available in the development environment. See [checkpoint-1.md](checkpoint-1.md) and [report.md](report.md) for implementation and executed evidence.

Checkpoint two remains: real cross-machine folder mounting and consistency tests; broader sandbox attack/network policies; persistent session/operation recovery; filesystem and sandbox performance measurements. Fixture upload is not a completed mounting milestone. The mounting ADR is proposed pending prototypes.

Later course work includes B6–B8, composite and custom tasks, comparison pairs and measured reporting. Model-course eligibility must be verified independently. Access to Luna and synthetic replay passes do not satisfy model comparison or quality requirements.
